## Abstract

Cardiovascular diseases (CVDs) remain the leading cause of mortality globally. This thesis presents ECG-TransCovNet, a hybrid CNN-Transformer architecture for multi-class arrhythmia detection designed for low-power deployment in resource-constrained healthcare settings like rural Pakistan.
